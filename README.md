# 💬 PChats

> **Secure access to your workspace.** A modern, sleek authentication and chat workspace platform interface designed with a dark, immersive theme and high-end security.


## ✨ Features

* **🔐 Secure Authentication:** Seamless sign-in and sign-up flows with encrypted connections[cite: 1].
* **✉️ Email Verification:** One-time code (OTP) verification support for new user registration.
* **🌙 Sleek Dark Mode UI:** Modern frosted-glass and dark aesthetic designed for workspace environments.
* **🛡️ Built for Security:** Emphasizes secure token handling and protected workspace access.
